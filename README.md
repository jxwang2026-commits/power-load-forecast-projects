# Power Load Forecasting Projects

基于机器学习的电力负荷预测项目，包括三种预测方式。

## 项目结构

### 1. load_predict_project
基础负荷预测项目。

### 2. load_predict_project_direct
Direct 多步预测方法。

### 3. load_predict_project_recursive
Recursive 递归多步预测方法。

## 技术栈

- Python
- Pandas
- NumPy
- scikit-learn
- XGBoost
- Matplotlib

## 目录结构

- `data/`：训练数据、测试数据及结果图
- `model/`：训练后的模型
- `src/`：训练与预测代码
- `utils/`：公共工具函数
- `log/`：运行日志目录，日志文件不纳入 Git

## 说明

该仓库用于记录电力负荷预测相关的机器学习实践。
